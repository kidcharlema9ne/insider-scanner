# Candidate factors register (not approved rules)

Anything on this list was found by looking at the 2026 pilot data, so it is a **lead, not an edge**. None of it changes an approved rule. Each item is to be carried into the frozen-rule commit as a **separate, named factor** and tested **once** on older years, with the rule written down before that run. Do not add or reword rows after seeing out-of-sample results; add a new row or a correction entry in `research_docs/SHARED_LOG.md` instead. Cohort = the 91 liquid (>= $3M a day) four-plus-buyer trades from the canonical selector (`research/canonical/cluster_selector.py`, which runs ChatGPT's recovered code unchanged). Returns are 21-session excess over SPY in the stock's ATR, with SPY shown beside the stock return (D-053).
